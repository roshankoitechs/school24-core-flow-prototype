Prototype Scope

This is a lightweight clickable prototype for the core School24 rebuild flow: multi-student dashboard, school-scoped canteen menu, cart/checkout, and Student Wallet top-up.

What It Proves

  • The selected student controls school, menu, wallet, and checkout context.
  • Parent balance and Student Wallet are separate payment sources.
  • Wallet top-up and order checkout are distinct flows.
  • Mobile navigation can support canteen, wallet, notifications/profile extensions.

Known Limitation

This is not a pixel-perfect Figma implementation. The private prototype template referenced in the archive was not available, so this standalone HTML file is used instead.
